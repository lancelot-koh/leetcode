## Sorting Comparison

| Algorithm | Time | Space | When |
|---|---|---|---|
| Merge | O(n log n) | O(n) | Need stability |
| Quick | O(n log n) avg | O(log n) | General |
| Heap | O(n log n) | O(1) | In-place |
| Count | O(n+k) | O(k) | Small range |
| Radix | O(d×n) | O(n) | Digits |

---

## Key Patterns

**When to sort:** Usually for optimization
- Sort to use two pointers
- Sort to process in order
- Sort to group similar items

**After sorting, think:** Can I use another pattern?
- Two pointers on sorted array
- Binary search on sorted array
