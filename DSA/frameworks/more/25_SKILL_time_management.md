# ⏱️ Time Management - The 45-Minute Clock

**Master pacing to solve problems completely**

---

## The 45-Minute Breakdown

```
0-2 min:   Clarify questions (5%)
2-5 min:   Discuss approach (7%)
5-25 min:  Code solution (44%)
25-35 min: Test & fix (22%)
35-40 min: Optimize (11%)
40-45 min: Follow-ups (11%)

TOTAL: 45 minutes
```

---

## Pacing Tips

### Early Red Flag: Taking Too Long on Approach

```
If at 5 min mark: Still not coding
→ Pick approach and start coding
→ Can optimize later if time allows
```

### Coding Time Management

```
At 15 min: Should have 50% of code done
At 20 min: Should be compilable/runnable
At 25 min: Should be complete
```

### Testing Time Management

```
At 30 min: Tested on 2-3 examples
At 32 min: Handle edge cases
At 34 min: Verify solution is correct
At 35 min: Ready for optimization
```

### If Behind Schedule

Priority order:
1. **Working code** > Perfect code
2. **Correct answer** > Optimized
3. **O(n²) that works** > Unfinished O(n)

---

## Watch Out For

⏰ **Time Thieves:**
- Overthinking approach (>3 min)
- Perfectionist coding (>20 min)
- Multiple test cases (only need 2-3)
- Premature optimization

---

## The Speed Secret

```
The key: Practice under 45-minute time pressure
- Take actual interview time pressure
- Time yourself on LeetCode
- Learn to code quickly + correctly
- Build muscle memory
```
