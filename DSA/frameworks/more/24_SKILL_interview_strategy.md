# 🗓️ Interview Strategy - How to Approach Problems

**Master the communication and thinking process**

---

## The Interview Flow (45 minutes)

```
0-2 min: Clarify & ask questions
2-5 min: Think & explain approach
5-25 min: Code the solution
25-35 min: Test & optimize
35-40 min: Discuss trade-offs
40-45 min: Answer follow-ups
```

---

## What Interviewers Are Judging

✅ **Communication**
- Do you explain your thinking?
- Can you clarify ambiguities?
- Do you ask good questions?

✅ **Problem-Solving**
- Can you break down complexity?
- Do you see patterns?
- Can you optimize?

✅ **Coding**
- Is your code clean?
- Does it handle edge cases?
- Can you write without bugs?

✅ **Collaboration**
- Do you listen to hints?
- Can you explain your approach?
- Do you think aloud?

---

## The Strategy

### 1. Clarify (2 min)

**Say out loud:**
- "Let me clarify a few things..."
- "Can I confirm the constraints?"
- "What about edge cases?"

**Why:** Shows you think systematically

### 2. Discuss Approach (3 min)

**Don't code yet!** Talk first:
- "I'll use sliding window because..."
- "This approach is O(n log n)..."
- "Trade-off: Fast but uses more memory"

**Why:** Interviewer can guide you

### 3. Code (20 min)

- Write clean code
- Think aloud: "I'm checking for null here..."
- Handle edge cases as you code

### 4. Test (10 min)

- Run through examples
- Check edge cases
- Fix bugs if found

### 5. Optimize (5 min)

- Can you reduce space?
- Can you reduce time?
- Is there a better approach?

### 6. Follow-ups (5 min)

- "What if we allow negative numbers?"
- "Can we do this in O(1) space?"
- Answer clearly

---

## Interview Red Flags (Avoid)

❌ **Don't say:**
- "I've never seen this before" (defensive)
- "Let me just code it" (no communication)
- "This is good enough" (not pushing yourself)
- "I don't know" (without trying first)

✅ **Instead say:**
- "This is similar to..." (pattern recognition)
- "Let me think out loud..." (communication)
- "Can I optimize this further?" (ambition)
- "Let me work through this step by step..." (systematic)

## Mental Technique: Think Aloud

```
PROCESS:
"Looking at this, I notice it's a graph problem.
The goal is finding shortest path.
I can use BFS because the graph is unweighted.
Here's my approach:
1. Build adjacency list
2. BFS from source
3. Track distance
4. Return when reaching target

Let me code this..."
```

This shows:
- Pattern recognition ✓
- Algorithm selection ✓  
- Clear thinking ✓
- Communication ✓
